# JS Libs

**A collection of focused JavaScript utility modules.**

Not a framework — the helpers that kept getting copy-pasted between projects until it was cheaper to publish them. Each module stands alone.

| Module | Covers |
|---|---|
| `array` | Array manipulation and transformation |
| `cookie` | Reading, writing and expiring cookies |
| `country` | Country data and lookup |
| `currency` | Currency formatting helpers |
| `dates` | Date parsing, formatting and comparison |
| `embed` | Embedding external media |
| `files` | File size, type and handling helpers |
| `geo` | Geolocation utilities |
| `http` | HTTP request helpers |
| `json` | JSON parsing and safe access |
| `metas` | Document meta tag manipulation |
| `number` | Number formatting and math helpers |

## Install

```bash
npm install innoboxrr-js-libs
```

Import the whole collection, or reach for a single module:

```js
import { currency, dates } from 'innoboxrr-js-libs';
```
